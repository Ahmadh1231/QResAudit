# Security

Report vulnerabilities privately through GitHub's private vulnerability reporting
for `Ahmadh1231/QResAudit`; do not open a public issue containing an exploit or
proprietary simulation data.

Supported security fixes target the latest release. Reports should include the
affected version, operating system, minimal reproduction, and impact. Expect an
initial acknowledgement within seven days when the maintainer is available.

Treat project paths, usernames, credentials, proprietary AEDT files, field exports,
and measurement data as sensitive. Never publish `.aedtresults` directories.
QResAudit validates paths and checksums, but users must review bundles before sharing.
