# QResAudit

QResAudit is a local-first evidence, validation, and analysis package for
electromagnetic simulations and quantum-device research.

Start with the [getting-started workflow](getting_started.md), then read the
[API stability policy](api_stability.md) and [HFSS evidence workflow](hfss_workflow.md).

Current validation has two deliberately separate layers:

1. deterministic software and analytical physics tests;
2. real-solver golden evidence, which remains gated until reviewed bundles are published.

QResAudit does not call an LLM at runtime.
