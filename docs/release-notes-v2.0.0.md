# QResAudit v2.0.0

QResAudit v2.0.0 provides a local, solver-independent electromagnetic evidence,
analysis, and research platform with a stable public API, deterministic benchmarks,
typed packaging, security auditing, and reproducible reports.

This release contains no proprietary project, geometry, solved result, institutional
design, or confidential research artifact. Users supply their own simulation evidence
locally. The published analytical and synthetic checks pass, while the separate
real-solver golden-evidence gate remains explicitly incomplete; package publication
is not an independent real-solver validation claim.

See `CHANGELOG.md` for the complete feature and hardening history.
